🚔 City Police Crime Analysis & Excel Dashboard
📌 Project Overview

This project analyzes raw crime incident data collected from multiple reporting sources for a City Police Department.

The objective is to clean and analyze crime data and develop an interactive Excel dashboard that helps police management understand crime patterns, identify high-risk areas, and improve police resource allocation.

🎯 Business Questions

The dashboard is designed to answer the following questions:

Which crime type occurs most frequently?
Which district has the highest number of crimes?
When does crime activity peak?
Which crime types cause the highest property loss?
Which areas have the highest crime severity?
What percentage of cases are resolved?
Which areas require more police attention?

🔄 Data Analysis Process
1. Raw Data

The original crime incident dataset was collected from different reporting sources.

2. Data Cleaning

The raw data was cleaned to improve data quality and consistency.

Key cleaning activities included:

Removing duplicate records
Handling missing values
Standardizing crime type names
Standardizing district and area names
Correcting date and time formats
Checking property-loss values
Validating crime severity values
Standardizing case-resolution status
3. Data Analysis

Pivot Tables were created to analyze:

Crime count by crime type
Crime count by district
Crime activity by time period
Property loss by crime type
Crime severity by area
Resolved vs. unresolved cases
Crime distribution by area
4. Interactive Dashboard

The final Excel dashboard contains interactive visualizations and slicers that allow police management to filter and analyze crime patterns.

🔍 Key Business Insights

**The final analysis highlights five major business insights:**

Highest Crime District
Identify the district with the highest number of reported crimes so additional police resources can be considered for that area.
Most Common Crime Type
Identify the crime category occurring most frequently to understand the department's primary crime challenge.
Peak Crime Period
Determine the time period when crime activity is highest to support better police shift planning and patrol scheduling.
Highest Property-Loss Crime
Identify the crime type responsible for the highest property loss so preventive measures can focus on high-impact crimes.
Case Resolution Rate
Calculate the percentage of cases resolved compared with total reported cases to evaluate overall case-resolution performance.

Note: The final values for these insights should be updated based on the results from the cleaned dataset and Pivot Tables.
